Privacy policy

rclone-dan is a private configuration of the open-source tool rclone, used only by its owner to manage files in the owner's own Google Drive.

  • The app accesses Google Drive only on the owner's own computer, at the owner's request.
  • OAuth tokens are stored only in the local rclone configuration file on that computer.
  • No data is collected, stored on any server, sold, or shared with third parties.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time at myaccount.google.com/permissions.
